# Contributing

Thanks for your interest in contributing to the PD multimodal subtype
discovery project (Paper 1 of the Parkinson's multimodal series).

## Development setup

```bash
git clone https://github.com/hwilner/pd-multimodal-subtype-discovery.git
cd pd-multimodal-subtype-discovery
pip install -e ".[dev]"
```

## Running tests

```bash
python -m pytest -q
```

All tests run on synthetic data generated by `pd_subtypes.simulate`; no
AMP-PD data access is required to develop or validate the codebase.

## Data access boundary

Real-data analyses require AMP-PD Tier 2 access (see
`docs/DATA_ACCESS.md`). Do **not** commit any participant-level AMP-PD
data, derived subject-level identifiers, or Terra workspace exports to
this repository. Code, synthetic data, and aggregate diagnostics only.

## Making changes

1. Open or pick up an issue (see the issue templates under
   `.github/ISSUE_TEMPLATE/`).
2. Create a feature branch from `main`.
3. Add or update tests covering your change; keep the suite under 90s.
4. Ensure `python -m pytest -q` passes locally.
5. Open a pull request using the repo card template and link the issue.

## Code conventions

- Source lives under `src/pd_subtypes/` (src layout).
- Type hints and NumPy-style docstrings for public functions.
- Keep methods transparent and documented; prefer simple, auditable
  implementations over opaque dependencies.
